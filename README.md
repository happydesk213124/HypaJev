# HypaJev

RisuAI 장기기억 플러그인. 대화 원문을 그대로 두고, 필요할 때 찾아서 넣어요. 요약 LLM 없이 **Jev(고르기만 하는 판단 모델) + 임베딩**만 써요.

## 어떻게 동작하나

- **원문은 Risu가 정해요.** Risu가 보낸 메시지는 건드리지 않고, 보내지 않은 이전 대화에서만 찾아요.
- **저장 (보낼 때, 요청에서 빠진 메시지만):** 원문을 문장 2~4개 조각으로 자르고 임베딩만 해요. Jev는 안 불러요. 버리는 문장이 없어요.
- **회상 (보낼 때):**
  1. 임베딩 + 글자(이름 · 숫자) 검색으로 후보 16개
  2. Jev가 조각마다 "지금 답하거나 이어 쓰는 데 필요한가" 0~3점. 빠진 근거가 있으면 한 번 더 찾아요
  3. 고른 조각의 앞뒤 조각을 같이 (맥락)
  4. Risu가 막 안 보낸 대화 끝부분을 조금
  5. 원래 순서대로 이어 붙여 최신 입력 앞에 넣어요
- **답장 뒤에는 아무것도 안 해요.**

## 저장

- **원문:** Risu 채팅 그대로예요. 플러그인이 따로 저장하지 않아요. 채팅을 옮기면 기억도 같이 가요.
- **벡터:** 이 기기 저장소에 조각마다 32바이트(1비트 × 256칸). 메시지 1000개면 수백 KB 정도예요. 다른 기기에서는 다시 계산해요.
- **세이브 파일:** 설정만 들어가요.

## 설치

1. [`hypajev.js`](https://raw.githubusercontent.com/happydesk213124/HypaJev/main/hypajev.js)를 받습니다.
2. RisuAI → 설정 → 플러그인 → 플러그인 추가에서 파일을 고릅니다.
3. 🧠 HypaJev → ⚙️ 설정에서 Jev 키(TypeSafe / OpenRouter)와 임베딩을 고르고 연결 테스트를 누릅니다.
4. Risu 채팅 범위(최대 컨텍스트)를 줄이면 토큰이 줄어요. Risu 자체 메모리(하이파 · 수파)는 꺼 두세요.
5. 이미 긴 채팅이면 🧰 도구 › **지금 전부 색인**을 한 번 누르세요. 안 눌러도 보낼 때마다 최근 것부터 100개씩 색인돼요.

다른 장기기억 플러그인과 같이 켜면 기억이 두 번 들어가요. 하나만 켜 두세요.

## 설정

| 설정 | 기본 | 뜻 |
|---|---|---|
| 기억 예산 | 600토큰 | 한 번에 넣는 기억의 최대 크기 |
| Jev 후보 수 | 16 | Jev가 매번 채점할 조각 수 |
| 앞뒤 조각 | 1 | 고른 조각 앞뒤로 몇 개씩 같이 |
| 최근 흐름 | 120토큰 | Risu가 막 안 보낸 대화 끝부분 |
| 보낼 때 색인 개수 | 100 | 이보다 많이 밀리면 최근 것부터 이만큼씩 |
| 넣는 위치 | 최신 입력 앞 | 프롬프트에 `[hypajev]`를 써 두면 그 자리 |

## 자동 업데이트

파일 머리의 `//@update-url`로 RisuAI가 이 저장소 `main`의 새 `//@version`을 감지해요.
